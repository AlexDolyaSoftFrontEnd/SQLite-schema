# SQLite Schema 

Данный репозиторий содержит продуманную схему базы-данных на **SQLite**, оформленную в виде отдельных SQL-файлов.  
Схема подходит как для **реальных pet-проектов**, так и для **демонстрации архитектурного мышления** на собеседованиях.

Проект демонстрирует:
- нормализацию данных,
- связи между сущностями,
- ограничения целостности,
- индексацию под реальные сценарии запросов.
